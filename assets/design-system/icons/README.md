# Icons

File Origin 独自のアイコン。16×16 のグリッド、線幅 1.5、線端と角は丸、塗り無し。ファイルの線色は `#7a8490`（両テーマの地で読める中間の灰）。
UI では `bundle.css` の `fo-i fo-i-<name>` を使う。CSS マスクなので `currentColor` で塗られ、ファイルの線色は効かない。14px（`fo-i-sm`）と 32px（`fo-i-lg`）にも縮尺できる。

- `search.svg` — 検索・QueryBar・見失い中のビュー
- `folder.svg` — フォルダを開く・監視フォルダ・GVFS
- `file.svg` — すべて・Zone.Identifier・拡張属性
- `link.svg` — 入手元なしのビュー・入手元の経路
- `copy.svg` — URL / ハッシュ / コマンドをコピー
- `external.svg` — 入手元をブラウザで開く
- `refresh.svg` — 再スキャン・再診断
- `import.svg` — 取り込み
- `download.svg` — ダウンロード（取得）
- `sliders.svg` — 設定
- `sidebar.svg` — サイドバーの開閉
- `clock.svg` — 最終スキャン・日時
- `hash.svg` — SHA-256 を計算
- `check.svg` — 完了・チェックボックスの印
- `alert.svg` — 要確認・警告
- `info.svg` — 補足
- `close.svg` — 閉じる・チップを外す
- `chevron-down.svg` — セレクト・開閉
- `chevron-right.svg` — 階層
- `arrow-right.svg` — 移動
- `branch.svg` — コピー（derived_from）
- `terminal.svg` — CLI
- `database.svg` — ブラウザ履歴・データ
- `plug.svg` — ブラウザ拡張・連携
- `shield.svg` — プライバシー・読み取りのみ
- `pencil.svg` — 手動登録
- `plus.svg` — 追加
- `more.svg` — その他メニュー
- `pulse.svg` — 診断
